# CPU 사용률 급증 대응 Runbook

## 증상
- cpu_usage 가 평시 대비 2배 이상, 5분 이상 지속
- GC 시간 증가, latency 동반 상승

## 원인 후보
1. 트래픽 급증 (정상 부하) — 요청 수(RPS)와 함께 증가했는지 확인
2. 무한 루프·비효율 코드 배포
3. GC 압박 (메모리 누수의 2차 증상일 수 있음) — memory_usage 추세 확인

## 조치 절차
1. RPS 증가 동반 시: HPA 상태 확인 후 scale out
2. 배포 직후 발생 시: 롤백 검토
3. 스레드 덤프·프로파일 수집 후 재시작
