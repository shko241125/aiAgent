# 배포 직후 5xx 에러 급증 대응 Runbook

## 원칙
배포 후 30분 이내 에러율이 기준선 대비 급증하면 **원인 분석보다 롤백을 먼저** 검토한다.
롤백으로 복구되면 원인은 변경분에 있다는 강력한 증거가 된다.

## 확인
1. 에러 시작 시각과 배포 완료 시각 비교 (카나리 단계별 에러율)
2. 신규 버전 파드에만 에러가 몰리는지 (버전 라벨별 에러율)
3. 설정 변경(ConfigMap/feature flag)도 배포와 동일하게 취급

## 조치 절차
1. 카나리 중이면 트래픽 0% 로 되돌림, 전체 배포면 이전 리비전으로 롤백
2. 롤백 후 지표 회복 확인 (에러율·지연)
3. 변경분 diff 검토, 재현 테스트 추가 후 재배포

## 주의
- DB 스키마 변경이 포함된 배포는 롤백 전 호환성 확인 (역방향 마이그레이션 필요 여부)
