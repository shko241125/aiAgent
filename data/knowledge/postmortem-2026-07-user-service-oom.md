# [포스트모템] 2026-07 user-service 반복 재시작(OOM)

## 요약
user-service 파드가 약 40분 주기로 OOMKilled 되며 로그인 지연·간헐적 5xx 발생. 이틀간 산발적 영향.

## 근본 원인
프로필 이미지 메타데이터 캐시에 크기 제한이 없어 메모리가 계속 증가함. 배포 변경과 무관하게 트래픽 증가로 드러남.

## 대응
- 임시로 memory limit 상향 및 replica 증설
- 힙 덤프 분석으로 캐시 객체 누적 확인, LRU 크기 제한 적용 후 재배포

## 교훈
- 재시작 전 힙 덤프 자동 확보 설정
- 메모리 사용량 추세 기반 조기 경보(재시작 전에 알림)
