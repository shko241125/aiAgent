# ADR-0001: 에이전트 프레임워크 — 자체 경량 코어 + 프레임워크 어댑터

- 상태: 채택 (v0.1)
- 날짜: 2026-09-30

## 배경
요구사항에 LangGraph·CrewAI 등 Agent Framework 활용과 자체 custom Agent 가 모두 포함된다.
프레임워크는 빠르게 변하고(메이저 버전 API 변경이 잦음), 운영 자동화는 승인 정책·감사 로그·
재현성이 중요해 실행 루프를 직접 통제할 필요가 있다.

## 결정
- 에이전트 계약(`BaseAgent`), 도구(`ToolRegistry`), 메모리, 오케스트레이터는 **자체 구현**을 기본으로 한다.
- LangGraph 는 `agents/orchestration/langgraph_adapter.py` 에서 **같은 에이전트 객체를 노드로 감싸는**
  어댑터로 제공한다 (체크포인트·interrupt 등 필요한 기능이 생기면 점진 도입).
- CrewAI 등 다른 프레임워크도 동일한 어댑터 방식으로 비교 실험한다.

## 결과
- (+) 핵심 로직이 프레임워크 버전에 묶이지 않음. 테스트가 가볍다(Fake LLM).
- (+) 승인 정책·trace 가 모든 실행 경로에서 동일하게 적용됨.
- (−) 체크포인트/재개, 스트리밍 등은 직접 구현하거나 어댑터를 통해 가져와야 함.
